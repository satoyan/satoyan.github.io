# satoyan

### Works for Flutter

1. **image_painter_rotate**

    - [pub.dev link](https://pub.dev/packages/image_painter_rotate)
    - Description: A Flutter image annotation widget forked from `image_painter`, with support for rotation, shapes, text, undo/redo, object removal, and image export.

2. **postal_jp**

    - [pub.dev link](https://pub.dev/packages/postal_jp)
    - Description: A Dart/Flutter package for retrieving Japanese address information from a 7-digit postal code via Zip Cloud, returning prefecture, city, town, kana readings, and API failures in typed results. This package is now discontinued and replaced by `japan_post_api_client`.

3. **go_router_builder**

    - <https://github.com/flutter/packages/pull/5865>
    - Description: A contribution to `go_router_builder` that added support for initializing `StatefulShellBranch` with a list of `NavigatorObserver`s, bringing builder support in line with the underlying `go_router` capability.

4. 語学学習アプリ

    - <https://apps.apple.com/jp/app/%E8%AA%9E%E5%AD%A6%E3%83%A9%E3%83%9C/id6763250026>
    - Description: 「語学ラボ」 is an iOS language-learning app that uses AI to generate level-appropriate reading material, lets users record read-aloud practice, extract key vocabulary into flashcards, and download high-quality offline English voices for model playback.
