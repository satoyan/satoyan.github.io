# satoyan

### Flutter関連の実績 / Flutter Works

1. **image_painter_rotate**

    - [pub.dev link](https://pub.dev/packages/image_painter_rotate)
    - 日本語: `image_painter` をベースにした Flutter 向け画像アノテーションウィジェットです。回転、図形描画、テキスト追加、Undo/Redo、オブジェクト削除、画像エクスポートに対応しています。
    - English: A Flutter image annotation widget forked from `image_painter`, with support for rotation, shapes, text, undo/redo, object removal, and image export.

2. **postal_jp**

    - [pub.dev link](https://pub.dev/packages/postal_jp)
    - 日本語: Zip Cloud を利用して7桁の郵便番号から日本の住所情報を取得する Dart/Flutter パッケージです。都道府県、市区町村、町域、かな情報を型付きの結果として返し、APIエラーも扱えます。現在は廃止され、`japan_post_api_client` に置き換えられています。
    - English: A Dart/Flutter package for retrieving Japanese address information from a 7-digit postal code via Zip Cloud, returning prefecture, city, town, kana readings, and API failures in typed results. This package is now discontinued and replaced by `japan_post_api_client`.

3. **go_router_builder**

    - <https://github.com/flutter/packages/pull/5865>
    - 日本語: `go_router_builder` へのコントリビューションです。`StatefulShellBranch` を `NavigatorObserver` のリスト付きで初期化できるようにし、`go_router` 本体の機能に合わせました。
    - English: A contribution to `go_router_builder` that added support for initializing `StatefulShellBranch` with a list of `NavigatorObserver`s, bringing builder support in line with the underlying `go_router` capability.

4. 語学学習アプリ

    - <https://apps.apple.com/jp/app/%E8%AA%9E%E5%AD%A6%E3%83%A9%E3%83%9C/id6763250026>
    - 日本語: 「語学ラボ」は、AI を活用して学習レベルに合った読解教材を生成し、音読の録音、重要単語の抽出と単語カード化、高品質な英語オフライン音声のダウンロード再生まで行える iOS 向け語学学習アプリです。
    - English: "LinguaLab" is an iOS language-learning app that uses AI to generate level-appropriate reading material, lets users record read-aloud practice, extract key vocabulary into flashcards, and download high-quality offline English voices for model playback.
